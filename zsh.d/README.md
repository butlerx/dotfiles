# zsh.d

Deployed to `~/.zsh.d`. Every `.zsh` file here is sourced by `zshrc`, in
filename order — the numeric prefixes are the load order, not decoration:

| File                            | Purpose                                              |
| ------------------------------- | ---------------------------------------------------- |
| `01-checks.zsh`                 | Guards for missing tools before anything else loads  |
| `02-setopt.zsh`                 | Shell options                                        |
| `03-history.zsh`                | History size, dedup, sharing                         |
| `04-colors.zsh`                 | `LS_COLORS` and friends                              |
| `05-environment.zsh`            | `PATH`, editor, pager, tool env vars                 |
| `06-completion.zsh`             | `compinit` and completion styling                    |
| `07-bindkeys.zsh`               | Key bindings                                         |
| `08-aliases.zsh`                | Aliases                                              |
| `09-functions.zsh`              | General shell functions                              |
| `10-docker-functions.zsh`       | Docker and container helpers                         |
| `11-git-worktree-functions.zsh` | Git worktree helpers                                 |
| `12-git-flow-completion.zsh`    | git-flow completion                                  |
| `13-p10k.zsh`                   | Powerlevel10k prompt configuration                   |
| `14-prompt.zsh`                 | Loads the prompt, falls back if the theme is missing |
| `15-hooks.zsh`                  | `precmd` / `chpwd` hooks                             |

Add a file with the next free prefix to extend the shell; `zshrc` picks it up
with no further wiring.

`14-prompt.zsh` sources `~/.dotfiles/powerlevel9k/powerlevel10k.zsh-theme`
directly from the repository — the submodule is never linked into `$HOME`. If it
is missing, the prompt falls back to a simpler theme rather than failing.

Completions live in `zsh-completions/` (`~/.zsh-completions`), which `zshrc`
puts on `fpath`. `_pets` there is generated by `pets sync` and gitignored.
